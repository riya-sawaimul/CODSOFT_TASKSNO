# Task 3: Data Visualization Dashboard

## 📌 Project Overview
This project presents an interactive dashboard for exploring Titanic passenger survival patterns using Python, Streamlit, Pandas, and Matplotlib.

## 🎯 Objectives
- Present important passenger statistics.
- Visualize survival and death counts.
- Compare survival rates by gender.
- Compare survival rates by passenger class.
- Explore survival rates across age groups.
- Allow users to filter passenger data interactively.

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- Matplotlib
- VS Code

## 📊 Dashboard Features
- Total passenger count
- Number of survivors and deceased passengers
- Overall survival percentage
- Survival distribution chart
- Survival rate by gender
- Survival rate by passenger class
- Survival rate by age group
- Interactive gender and passenger-class filters
- Expandable passenger data table

## 📁 Dataset
The dashboard uses `Titanic_cleaned.csv` from the `Task1_Data_Cleaning` folder.

## ▶️ How to Run

1. Install Python.
2. Install the required libraries:

   `python -m pip install streamlit pandas matplotlib`

3. Open the main project folder in VS Code.
4. Run the following command in the terminal:

   `python -m streamlit run Task3_Dashboard/dashboard.py`

5. Open the local address shown in the terminal if the browser does not open automatically.
