# CodSoft Data Analytics Internship

Welcome to my CodSoft Data Analytics Internship repository! 👋

This repository contains the three tasks I completed during my internship to practice Python, data analysis, and data visualization.

## 📂 Projects

### Task 1: Data Cleaning and Preprocessing
- Cleaned the Titanic dataset using Pandas.
- Handled missing values.
- Removed the Cabin column because it contained many missing values.
- Saved the cleaned dataset for further analysis.

**Technologies:** Python, Pandas

📁 Folder: `Task1_Data_Cleaning`

### Task 2: Exploratory Data Analysis (EDA)
- Explored the Titanic dataset.
- Examined missing values and duplicate records.
- Analyzed survival rates by gender, passenger class, and age group.
- Created charts to visualize the findings.

**Technologies:** Python, Pandas, Matplotlib

📁 Folder: `Task2_EDA`

### Task 3: Data Visualization Dashboard
- Built an interactive Titanic survival dashboard.
- Displayed passenger statistics and survival rates.
- Created visualizations by gender, passenger class, and age group.
- Added filters for gender and passenger class.
- Included a passenger data table.

**Technologies:** Python, Streamlit, Pandas, Matplotlib

📁 Folder: `Task3_Dashboard`
