# Task 2: Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to understand passenger survival patterns.

## 🎯 Objectives
- Understand the dataset structure.
- Identify missing values and duplicate records.
- Analyze passenger survival rates.
- Explore survival patterns by gender, passenger class, and age group.
- Visualize findings using bar charts.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- VS Code

## 📊 Analysis Performed
1. Displayed the first five rows of the dataset.
2. Checked dataset dimensions and summary statistics.
3. Identified missing values and duplicate records.
4. Calculated overall survival counts and percentages.
5. Analyzed survival rates by gender.
6. Analyzed survival rates by passenger class.
7. Analyzed survival rates by age group.

## 📈 Visualizations
- Titanic Survival Rate by Gender
- Titanic Survival Rate by Passenger Class
- Titanic Survival Rate by Age Group

## 🔍 Key Findings
- Female passengers had a higher survival rate than male passengers.
- First-class passengers had a higher survival rate than passengers in lower classes.
- Survival rates varied across age groups.

## ▶️ How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas matplotlib`
3. Open the project root folder in VS Code.
4. Run the following command in the terminal:

   `python Task2_EDA/task2_eda.py`

## 📁 Dataset
The analysis uses `Titanic.csv` from the `Task1_Data_Cleaning` folder.
